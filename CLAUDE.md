## 3. Facts established before this tura

Verified on `main` at `95a83e9`, 07.10.2026. Re-check them on your starting commit.

### The rule

With `inset = geometry.glassInset` (11.5):

- glass width = leaf width minus `2 x (leafStile.face - inset)` = leaf W - 105
- glass height = leaf height minus `(leafTop.face - inset) + (leafBottom.face - inset)` = leaf H - 52.5 - 55.5 = leaf H - 108
- daylight width = leaf W - 2 x 64, daylight height = leaf H - 64 - 67

The door engine in the same file already works this way (`calculations.js`, around lines 1199, 1200, 1323, 1335 to 1339: `secLeafBottom`, `gh = leaf.h - (leafTop.face - inset) - (leafBottom.face - inset)`). Use it as the pattern.

### Where the casement engine assumes one width today (`src/engine/calculations.js`)

- Around line 655: `secLeaf` from `els.leafStile.face`, used for all four members, the arched top rail and the leaf ring (lines 919 to 944).
- Around line 662: `glassDed = casementGlassDeduction(p)`, one number, used for both glass width and height (lines 985, 986).
- Around lines 811 and 991: bars. `casementLeafBars({ ..., stile })` and `leafBarsToUnit(leafBars, stile, unitInset)` in `src/engine/casementBarGrid.js` take one face and inset the leaf by it on all four sides.
- Around line 1020: leaf weight, `kgPerM(els.leafStile.face, ld) * leafRun`, one face for the whole run.
- Around line 698: the arched glass bottom edge ALREADY uses `els.leafBottom.face`. Make sure the bottom rail is not counted twice on an arched leaf.
- Beading is `pane perimeters x 1.15` (around line 1046), so it follows the glass unit. Bead tape and glass area follow too.
