## §3 Geometry

Coordinates: mm, y up, x = 0 on the window axis, y = 0 on the **arch-start line** (where the
straight jambs / stiles begin). Outer arcs run counter-clockwise from the right arch-start point
over the apex to the left one. Every contour of a window shares the same centres; an offset only
shrinks the radii (concentric rule). Contours are clipped at the arch-start line (and at the axis
for the pointed apex).

| Shape | Centres | Rise (default, PSW) | Free rise? |
|-------|---------|---------------------|------------|
| `segmental` | 1, below the line: `R = (W²/4 + h²) / 2h` | 0.20 W | 0.10–0.45 W |
| `semi-circle` | 1 on the line, `R = W/2` | 0.50 W | fixed |
| `gothic-equilateral` | 2 at the opposite arch-start points, `R = W` | 0.866 W | fixed |
| `gothic-drop` | 2 inside the span, `c = (h² − W²/4)/W`, `R = W/2 + c` | 0.70 W | 0.55–0.85 W |
| `three-centre` | 2 haunch centres on the line (`r = h/2`) + 1 crown centre below it, crown radius from tangency | 0.325 W | 0.15–0.45 W |

Width limits 400–1500 mm (PSW `MIN_WIDTH` / `MAX_WIDTH`). Rise must leave a straight part > 0.
Rings read from the casement profile: frame head `0 → frameHead.face`, leaf top
`leafAtJamb → leafAtJamb + leafTop.face`, glass line `leafAtJamb + leafTop.face − glassInset`.
Errors are `ArchError` with a readable message (exporter turns them into the button tooltip).

## §4 Spec mapping (`windowSpec.arch`)

`arch: { shape, rise, hinge } | null` — null unless `casementType === 'arched'` (PSW) or a
PC-native `archShape` exists.

| PSW field | PC |
|-----------|----|
| `casArchShape` gothic-arch / semi-circle / segmental-arch / elliptical-arch | gothic-equilateral / semi-circle / segmental / three-centre (unknown values kept verbatim → export reports them) |
| `casArchHinge` `'right'` (form radio labelled **"Left Hinge"**, `online-estimate.html` 887) | `hinge: 'left'` |
| `casArchHinge` `'left'` (radio labelled **"Right Hinge"**) | `hinge: 'right'` |
| missing shape / hinge | `semi-circle` / `left` (PSW defaults) |
| (none — PSW has no rise) | `rise: null` → shape default; PC-native `archRise` honoured |

## §7 Segment planner

Per arc of a ring, for N = 1…maxPieces: split by equal outer angle; project each piece onto its
board axes (bisector = width, outer chord = length) using exact arc extrema; board = projected
width + allowance; stock = narrowest board ≥ that. Pieces with a clipped end (arch-start,
apex) use the same projection — the closed form `ρo − ρi·cos(φ/2)` only holds for radial-radial
pieces. **D13 default = fewest pieces that fit a stock board; alternative = plan on the
narrowest board** (both returned, alternative printed). No board fits → `stock: null`,
`noStock: true`, no throw; the exporter refuses with the needed width in the message.

Joints: radial partition lines inside an arc, the vertical axis line at a gothic apex, the shared
radial line at a three-centre tangent point. Arch-start cuts are not joints.

## §8 DXF

R12 via `dxfWriter.js`. Rows top-down, 200 mm apart: FRAME HEAD contour + assembly, FRAME HEAD
pieces flat, LEAF TOP contour + assembly, LEAF TOP pieces flat. Origin = bottom-left of the
drawing. Layers: `CONTOUR` 7 (finished member), `ASSEMBLY` 8 (stock boards, assembled and flat),
`PIECES` 5 (piece contours laid flat, chord horizontal, centred in the board), `FINGER` 1 (joint
planes only — no teeth), `TEXT` 94 (labels, shape/size/hinge line, face/offset/lengths, per-arc
plan with the D13 alternative, `FINGER 15/16/3.8`). Merged export stacks windows 300 mm apart.

## §9 Export / UI

`archParamsForWindow(windowSpec, name)` → `{ params }` or `{ skip }`; single window
`{name}_arch.dxf`, pack `{label}_arch.dxf`. WindowDetailPage button plans under the batch's
profile snapshot (`withProfiles`), the pack button under the active profile.
